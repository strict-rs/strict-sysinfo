## Supported OSes

It currently supports the following OSes (alphabetically sorted):

 * Android
 * FreeBSD
 * NetBSD
 * iOS
 * Linux
 * macOS
 * Raspberry Pi
 * Windows

You can still compile and use `sysinfo` on non-supported OSes, it'll simply do nothing.

The minimum-supported version of `rustc` is **1.95**.
